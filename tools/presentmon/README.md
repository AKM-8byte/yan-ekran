# PresentMon

FPS ölçümü için Intel/GameTechDev'in açık kaynak **PresentMon** konsol aracı kullanılır.
Kurulum gerektirmez, sürücü yüklemez (Windows ETW olaylarını okur).

1. https://github.com/GameTechDev/PresentMon/releases adresinden `PresentMon-<sürüm>-x64.exe` dosyasını indir
   (test edilen sürüm: **v2.6.0**).
2. Bu klasöre **`PresentMon.exe`** adıyla koy.
3. Derleme bu dosyayı çıktı klasörüne `tools/presentmon/PresentMon.exe` olarak kopyalar.

Dosya yoksa program çalışır, FPS kutucukları "—" gösterir.
